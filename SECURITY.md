# Security & Responsible Use

## Reporting a vulnerability

Please report security issues privately through GitHub's
"Report a vulnerability" feature on this repository rather than a public issue.

## Responsible use

Specter reads publicly available data (job boards, public GitHub metadata).
You are responsible for complying with applicable laws (including GDPR/CCPA),
GitHub's Terms of Service and Acceptable Use Policies, and each target site's terms.
Do not use Specter to send unsolicited bulk email or to harass individuals.
